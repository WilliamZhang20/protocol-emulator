The lane controller's program store (experiments/grid_fabric/LANE_CORE.md,
"Program store"). The LEF is a copy of the IHP-Open-PDK view at the
revision the GDS action pins (2bbec755dc67ca3db0261c3d6163e15735d66710,
ihp-sg13g2/libs.ref/sg13g2_sram; sg13cmos5l_sram links to it), read by
odb_sram_stripes.py for this master's Metal4 supply lattice. The flow
itself takes every view from pdk_dir (src/config.json MACROS).
